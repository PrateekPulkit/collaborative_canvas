# Flam Collaborative Canvas

A smooth, real-time collaborative drawing canvas built using React and HTML5 Canvas. Includes infinite panning, zoom, shape tools, undo/redo, and support for multiplayer sync across tabs.

## Features (Planned & In-Progress)
- **HTML5 Canvas Engine**: Optimized drawing with speed-based stroke smoothing (calligraphy effect).
- **Infinite Workspace**: Drag-to-pan and mouse-wheel zoom.
- **Rich Elements**: Pen drawing, lines, arrows, rectangles, circles, sticky notes, and text tools.
- **Interactive Multi-select**: Scale, rotate, translate, and re-order elements.
- **Collaborator Sync**: Real-time cross-tab synchronization via BroadcastChannel.
- **Simulated Multiplayer**: Visual mock cursors, drawings, and chat bubble indicators from simulated active users to test features immediately.
- **Premium Dark Glassmorphic Design**: Glowing colors, blur backdrop effects, smooth CSS animations.
